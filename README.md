# Trabalho de Algoritmos

## Sobre o projeto

Este projeto reúne a implementação de algoritmos fundamentais desenvolvidos durante as atividades da disciplina. O objetivo é praticar lógica de programação, organização do código, programação defensiva e testes unitários.

## Algoritmos disponíveis

Os algoritmos implementados em JavaScript são:

- **Contagem:** conta os números dentro de um intervalo.
- **Fibonacci:** gera uma sequência de Fibonacci.
- **MDC:** calcula o máximo divisor comum entre dois números.
- **Primo:** verifica se um número é primo.
- **Quicksort:** organiza os elementos de um array em ordem crescente.
- **Somatório:** calcula a soma dos números de 1 até o valor informado.

## Programação defensiva

Os algoritmos possuem validações para identificar entradas inválidas, como valores que não sejam inteiros quando exigido, tipos incorretos e arrays com elementos inválidos.

Quando necessário, são utilizados erros para impedir que o programa continue com dados inadequados.

## Tecnologias utilizadas

- JavaScript
- Node.js
- npm
- Jest

## Como executar o projeto

### 1. Instalar as dependências

É necessário ter o Node.js instalado. Na pasta principal do projeto, execute:

```bash
npm install
```

### 2. Executar os testes

Para executar todos os testes unitários, utilize:

```bash
npm test
```

## Testes unitários

Os testes foram desenvolvidos com Jest, contendo verificações de funcionamento e de entradas inválidas para os seis algoritmos.

**Resultado da execução:** 6 suítes de testes aprovadas e 28 testes aprovados.
